## Current Approved Product / Route Constraints

- 当前产品方向：**Personal State / Information & Action Desktop**；
- CORE = `Today / Plan / Tracks`；
- V0 = `Thin Tracks + Usable Plan + Derived Today`；
- Workbench 自己拥有 Core Personal State；
- Today 主要是 derived view，不复制 Plan / Tracks 的业务事实；
- Today “已完成”只是当天视觉确认，不推进 Plan / Track，不做完成率 / streak / 评分；
- Current Vector 日期区间禁止重叠；
- recurrence 采用 series definition + dynamic occurrence + exception；
- recurrence edit / delete V0 只支持“仅这一次 / 整个循环”；
- 核心数据本地可靠保存；V0 需要 restart recovery、手动 backup / restore 与 migration；
- system tray 属于 V0 Required；开机启动 Deferred；
- Plan 不以万能事项表单强行统一不同用户语义；
- AI 不是 V0 成立前提；Milestones / AI / Sync / Custom / Plugin / SDK 等继续 Deferred；
- 原 AI Collaboration V0 保持 `HOLD / HISTORICAL / FUTURE RE-DISCOVERY`；
- Owner Discussion & Promotion Gate 继续强制生效。

8. Track stable identity 与 Plan link；
