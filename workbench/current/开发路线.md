# 3. Route-level Architecture Contracts

后续实现路线必须保护：

1. **Electron** 为 V0 Desktop Host；Tauri 只保留未来重新评估资格，不双维护；
2. **SQLite** 为 V0 唯一 local canonical persistent store；
3. DB 位于 Windows per-user application data location；
4. Track / Plan 持有业务事实；Today 主要是 derived view；
5. Today acknowledgement 只是当天视觉确认，不推进 Plan / Track；
6. Track / 普通对象 / Series 使用 immutable internal ID；
7. Occurrence identity = `SeriesStableID + OriginalScheduledOccurrenceKey`；
8. `date-only != timestamp`；local recurrence 使用本地日历时间语义；
9. Current Vector `[startDate, endDate]` 两端包含，日期区间禁止重叠；
10. recurrence = series definition + dynamic occurrence + persisted exception；
11. V0 recurrence edit/delete 只有“仅这一次 / 整个循环”；
12. manual backup 使用一致性 SQLite snapshot；restore 前自动 safety snapshot + validation；
13. schema version + ordered transactional migration 从 V0 存在；升级前自动 safety backup；
14. system tray 是 V0 Required；close → tray，tray restore / real exit；开机启动 Deferred；
15. Future AI / sync / Milestones / Plugin / SDK 不提前平台化。
