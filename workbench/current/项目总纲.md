## 1. 当前产品方向

Personal Workbench 当前正式方向已经从原 AI Collaboration V0 Pivot 为：

> **长期驻留在电脑上的个人信息与行动桌面（Personal State / Information & Action Desktop）。**

核心问题：Owner 已经拥有大量长期规划、个人资料、未来安排和日常事项，但这些信息散落在 ChatGPT、GitHub、脑中和其它工具里，缺少一个长期驻留、可以持续查看并直接维护当前生活状态的个人工作台。

当前产品核心结构：

```text
CORE
├─ Today
├─ Plan
└─ Tracks
```

当前 V0：

> **Thin Tracks + Usable Plan + Derived Today**

原 AI Collaboration V0 保持 `HOLD / HISTORICAL / FUTURE RE-DISCOVERY`，不参与当前 Product / Roadmap Authority。

完整 Product Definition 见：`current/产品定义.md`。

## 7. 新方向的重要产品边界

后续架构不得破坏以下产品原则：

- Workbench 自己拥有 Core Personal State；
- Today 是当前日期派生视图，不建立第二套 live truth；
- Workbench 用于看清 / 维护状态，而不是自动监督或评价 Owner；
- V0 不膨胀成 Calendar + Todo + Knowledge + Habit + Finance + Health + AI 超级 App；
- AI 不是 V0 成立前提；
- 桌面高频 / 长期驻留是体验目标，但技术承载方式未冻结；
- 维护成本必须低于它节省的记忆、查找和重新规划成本。

## 8. Owner Discussion & Promotion

重大 Product / Architecture / Roadmap / Task Axis 决定继续强制执行：

```text
Working Draft
→ Owner Discussion
→ Owner explicit approval
→ GitHub Promotion
→ 如涉及 Gate，再由 00 审核
```
