```text

→ Coding Agent
```

当前状态：

```text

= HOLD / HISTORICAL / NON-CURRENT
```

## 4. Authority

默认权威顺序：

1. 用户当前明确指令；
2. 当前项目 GitHub 中已批准的 Product / Architecture / Roadmap / Decision；
3. implementation repository 当前代码、测试、运行事实和 Git HEAD；
4. Vibe-Coding 当前治理规则与适用 Skill；
5. 当前项目其他聊天中的已确认结论；
6. `discussion/`、`research/`、`99_归档/workbench/`、历史资料与模型记忆。

归档资料不构成 current authority，即使其中曾记录 `PASS` / `DECIDED`。

若两个 current source 冲突，不得自行拼接第三套方案；应进入冲突识别与 Owner 裁定流程。

## 5. 当前产品方向重评

当前不是“已经 Pivot 到 Personal OS”，而是进入一次新的 Product Discovery。

至少需要比较：

### Candidate A｜恢复 / 继续 AI Collaboration

仅当关键技术条件或产品路径出现新的可行证据时重新考虑。

### Candidate B｜Personal OS / Life Operating System

探索是否围绕长期方向、Tracks、Plan、Today、Review 等形成更稳定、Owner 高频使用、较少依赖外部平台的核心闭环。

### Candidate C｜长期组合

长期 Personal Workbench 可能同时容纳 Personal OS 与 AI Collaboration，但当前仍必须选择第一条真实可验证纵向，不能因为“未来都想要”而扩大 V0。

以上都是讨论选项，不是 current Product Decision。

## 6. 项目推进顺序

方向重评后的正确顺序重新从 Product 开始：

```text
Product Direction Discovery
→ Owner Direction Decision
→ Primary Purpose / Core Value
→ Product Definition
→ G0.1 Product Baseline
→ G0.2 Scope
→ Draft Task Axis
→ Reference Audit
→ Risk / Omission / Ordering Review
→ Owner Discussion
→ Revised Task Axis / Architecture
→ Owner Approval
→ Route Freeze
→ Implementation
→ Validation
→ Independent Review
→ Owner UAT
→ Decision Propagation
```

旧 AI Collaboration V0 的 G0.1 / G0.2 PASS 仅属于已归档路线，**不能继承到新方向**。

## 7. Owner Discussion & Promotion

重大 Product / Architecture / Roadmap / Task Axis 决定必须：

```text
Working Draft
→ Owner Discussion
→ Owner explicit approval
→ GitHub Promotion
→ 如涉及 Gate，再由 00 审核
```

当前 Personal OS 候选必须先由 `01｜产品定义` 与 Owner 完成真实 Product Discovery。未经明确批准，不得创建新的 current Product Definition、Roadmap 或 Architecture。

## 8. Implementation 状态

当前：

**Implementation = NOT AUTHORIZED**。

在新产品方向完成必要 Stage 0 Gate 并 Route Freeze 之前：

- 不开始正式功能编码；
- 不搭建大规模产品脚手架；
- 不因参考图提前实现 Today / Plan / Tracks / Dashboard；
- 不因旧历史重新绑定 DSH / Agent orchestration；
- 低成本探索若确有必要，必须明确标记 `EXPLORATION / SPIKE / PROTOTYPE`。

- `00｜项目总控`：Stage / Gate / Status / 跨域冲突 / Decision Propagation；
- `01｜产品定义`：当前下一主线，负责 Product Pivot Discovery 与新 Product Definition；
