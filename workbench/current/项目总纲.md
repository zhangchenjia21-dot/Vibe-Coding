## 3. Frozen implementation foundation

当前 V0 冻结：

- Desktop Host：**Electron**；
- Canonical local persistence：**SQLite**；
- Tracks / Plan authoritative，Today 主要 derived；
- Today acknowledgement 只保存当日视觉确认；
- immutable internal IDs；
- occurrence identity = `SeriesStableID + OriginalScheduledOccurrenceKey`；
- date-only / local wall-time / instant 明确分离；
- Current Vector `[startDate, endDate]` inclusive + no-overlap；
- recurrence = series + dynamic occurrence + exception；
- whole-series edit 清除旧 exceptions 前提示 / 确认；
- consistent backup / validated staged restore / safety snapshot；
- schema version + ordered transactional migration + upgrade safety backup；
- system tray 为 V0 Required；close → tray；tray restore / real exit；开机启动 Deferred。

具体 SQLite binding / ORM、UI component framework、字段级 production schema 等仍属于 implementation detail，不在总纲层冻结。

## 7. 当前产品边界

后续实现不得破坏：

- Workbench 自己拥有 Core Personal State；
- Today 是当前日期派生视图，不建立第二套 live truth；
- Workbench 用于看清 / 维护状态，而不是自动监督或评价 Owner；
- V0 不膨胀成 Calendar + Todo + Knowledge + Habit + Finance + Health + AI 超级 App；
- AI 不是 V0 成立前提；
- 维护成本必须低于它节省的记忆、查找和重新规划成本。

继续 Deferred：Milestones / AI-assisted Track Update / Google Calendar sync / Custom Functions / Launch Target / Knowledge / Habit / Finance / Health / AI Collaboration / Plugin / SDK / Page Builder / multi-device sync 等。
