## FUTURE-001｜Today 事项快捷启动 / Launch Target

状态：**DEFERRED / FUTURE**  
首次记录：2026-09-06

### 用户需求

Personal Workbench 未来希望具有长期驻留在电脑上的“个人桌面 / 行动入口”体验。Owner 在 Today 中明确当前事项后，再根据事项进入真正完成工作的外部环境。

因此，未来可允许 Today / Plan 中的事项卡片配置一个可选的 `Launch Target / 开始入口`。

例如：

```text
事项：面试准备
关联 Track：求职
Launch Target：ChatGPT 求职 Project

事项：CPA 会计学习
关联 Track：CPA
Launch Target：学习资料 / 本地文件 / 网站
```

### 候选体验

在 Today 事项卡片中除“标记已完成”外，可出现一个轻量入口，例如：

```text
[打开] / [开始]
```

点击后可打开该事项实际需要的工作环境，例如：网站、本地文件或文件夹、桌面程序、ChatGPT Project / Conversation、GitHub 页面或其它未来支持的 Workspace。

### 产品意义

该能力不是为了把所有工具内嵌进 Workbench，而是让 Workbench 在完成“告诉 Owner 现在该做什么”之后，进一步成为进入真实工作环境的快捷入口。

候选链路：

```text
Workbench Today
→ 看清当前事项
→ 点击事项 Launch Target
→ 打开真正完成工作的工具
```

### 当前边界

- **不进入当前 Candidate V0**；
- 当前 Today 只需承担信息呈现与轻量 Completed 反馈；
- 不为此预建通用 App Launcher、自动化平台或插件系统；
- 待 V0 实际使用后确认是否存在足够高频的“从事项进入工具”需求，再决定是否 Promotion。
