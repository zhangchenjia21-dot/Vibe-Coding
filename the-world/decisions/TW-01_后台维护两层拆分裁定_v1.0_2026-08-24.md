# TW-01 后台维护两层拆分裁定 v1.0

## 1. 背景与问题

真实试玩（`games/luan-shi-sanguo`）中发现：World Core 的回合后 durable maintenance step 耗时长。根因在当前 `plugins/the-world-core/lib/提示文本.js` 的 `buildMaintenanceText` 语义——它要求每回合按 7 个 Owner 逐一判断更新，模型倾向于重读文件、多文件巡视与整段重写，导致正文前后出现大量 read / think / edit 记录与长尾等待。

已否决方案（GPT 提出）：把维护整体推迟到下一次玩家输入之后。否决理由：

1. 拉长玩家输入后的响应延迟；
2. 推迟过回合边界的维护在 Session 结束 / 崩溃时丢失——即 TW-00.5 已实证的 Persistence Maintenance Attrition 换马甲回归。

## 2. 正式裁定：两层维护拆分

### Tier 1｜回合内 delta 捕获（每回合，秒级）

- 与叙事同一次推理完成判断："本轮 durable 变化：无 / 有（列出）"，不另起长思考；
- 无变化 → 零写入；
- 有变化 → **只向 `memory/DELTAS.md` 追加 1–3 行**（append-only，不重读、不重写、不多 Owner 巡视）；
- 唯一例外：场景锚点（时间 / 位置 / 当前选择）变化可直接小改 `state/CURRENT.md`；
- **事实必须当回合落盘**，保证崩溃 / Session 结束不丢。

### Tier 2｜检查点归并（可推迟）

把 DELTAS 分发到正确 Owner（characters/、THREADS.md、LEDGER.md、mechanics/、PLAYER.md），清空 DELTAS，刷新 RECENT.md。触发点：

- 场景收束 / 时间跳跃 / 阶段切换（GM 语义判断）；
- 每 N 玩家回合——**与 Save Policy 的回合计数共用同一检查点**（v0.2 已有每 5/10/20 回合自动存档），归并先于存档快照执行，玩家只感受一次节奏性停顿；
- Session 结束 hook（若 DSH seam 支持）。

## 3. 连带语义更新

- **恢复路径**：fresh-session recovery 必须把未归并的 `memory/DELTAS.md` 视为有效事实源（恢复时先归并或直接纳入上下文）；
- **存档语义**：saves 全量复制已含 DELTAS，恢复快照天然安全；
- 不违反"维护职责不衰减"：职责不变，变化的只是单位成本与归并时机；
- 不需要新机制 / schema / validator，纯 prompt + hook 语义（Markdown-first、Freedom Before Prevention 均不受影响）。

## 4. 实施范围（Owner：World Core plugin）

1. `plugins/the-world-core/lib/提示文本.js`：
   - 重写 `buildMaintenanceText` 为 Tier 1 捕获语义；
   - 新增 `buildConsolidationText`（Tier 2 归并指令）；
   - `buildRecoveryInjection` 增加 DELTAS 读取；
   - Game Mode 主段落中 Owner 巡视那条改为捕获 + 检查点语义。
2. 插件 hook：复用存档策略已有的玩家回合计数，N 回合注入归并 step；里程碑归并由 prompt 语义承担。
3. `games/_template/`：新增 `memory/DELTAS.md`。
4. 实施时回写 `the-world` 正式文档（TW-01 计划 WC-02 / 架构文档），本文件不替代项目仓库 truth。

## 5. 验证口径

在 `games/luan-shi-sanguo`（或新 TW-01 测试局）实测：

- 长局中每回合维护的 read/edit 次数显著下降（目标：常规回合 0–1 次写，无重读）；
- durable facts 无丢失（对照 Tier 1 捕获）；
- 检查点归并正确分发 Owner；
- 含未归并 DELTAS 的全新 Session 恢复同一世界；
- GM 文笔与主动性无明显变化（Gate A 口径）。

## 6. 协同记录（非解决方案）

"加长输出文本以覆盖维护时间"：作为体验协同成立（流式输出下阅读时间覆盖 Tier 1 秒级捕获），但**不给模型 blanket 加长指令**——只授权在 Life Loop / 场景质感处铺厚，避免注水文本与上下文膨胀。它掩盖不了分钟级维护，不能替代本拆分。
