允许显式延后，例如：

这不是删除需求，而是移出当前 G9 前关键路径；进入 G11 / Alpha 前重新拉回 Required。

## 5. 声明式动态 UI 当前模型

正式架构：

```text
Definition / future Asset
= 声明安全 UI 需求与信息架构

Runtime / Adapter / Projection
= 拥有 authoritative state 与当前 player-safe live values

Host
= 校验、组装、布局、渲染、受控交互

Player
= 拥有 Surface 最终排序 preference
```

禁止：

- arbitrary JS / React / DOM / eval / CSS；
- direct Game State mutation；
- asset-owned arbitrary state path；
- asset-owned selector / query / expression DSL；
- 浏览器读取 hidden/private Runtime State。

当前 G8 只用 handwritten typed definitions 验证 Host；External Asset machine schema 留给 G9。

旧 One Draft / Five Sections production path 在 WEB-04 Host Creation bridge 完成后退休。

## 10. Agent 分工

默认 Owner-aligned：

```text
ChatGPT
→ Product / Architecture / Stage Gate / Independent Review

Codex
→ Contract / Runtime / Bootstrap / Data / Provider / Test

Grok Build
→ Product UI / Interaction / Visual
```

原则：

- UI 问题回 Grok；
- Runtime/Contract 问题回 Codex；
- 不为单纯代 push 强制二次交接。

Git 使用：

> **Executor-owned Git Integration**

执行者完成自己的 task-owned diff 后自行 Gate、精确 stage、commit、push。

跨 Owner 集成、冲突、复杂仓库操作再由专门 Integration Owner 接管。

Push success ≠ Independent Review PASS。
