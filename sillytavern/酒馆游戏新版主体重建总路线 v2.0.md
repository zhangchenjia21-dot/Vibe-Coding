## 6. G9-02C｜Context Orchestration Foundation

在 02B PASS 后开始。

目标链：

```text

+ enabled/pruned Routing Directory
+ minimal current context
→ Model-first routing
→ Program structural validation + state-mandatory augmentation
→ JIT owner projections
→ bounded owner-preserving join
→ domain handling / Formal Outcome
→ outcome-gated downstream continuation
```

必须验证：disabled Module fail-closed、background deterministic progression zero model call、large registry selected projection、no transitive prompt expansion、Bounded != Starved、Open Attempt。

新增 People Directory stress gate：

```text
Known Character Directory size ↑↑↑
ordinary unrelated Turn context ≈ bounded
```

current-scene characters 与 referenced/relevant known characters 分开选取；People Directory 不直接等于 Prompt inclusion。
