## 4. Creation 规则修正

### Creation Field != Entity Record

字段必须先分类为：

- scalar definition
- structured list
- semantic/materialization guidance
- world constraint
- private seed
- runtime state seed
- product metadata

再决定 materialization owner。

### AI-assisted configured path

允许 / 要求 bounded model semantic materialization。

### Manual / no-key path

继续支持 deterministic create，但不得用 generic placeholder 假装理解复杂自由文本。

```text

↓ snapshot / bind
```

> Source assets are templates; game-local assets are living canonical world definitions.
