## 3. 开放世界长期架构

新增第 16 号核心裁定：

`16_酒馆游戏_RuntimeWorldMaterialization与开放世界增长裁定_v1.0_2026-08-18.md`

长期世界目标不是：

```text
开局预枚举全部人物/地点/物品
→ 永不增长
```

也不是：

```text
Narrative Model 自由写什么就自动成为世界事实
```

而是：

```text
Authored / Created World Anchors
+
Authoritative Runtime State
+
Bounded Model-generated World Proposals
+
Program-validated JIT Materialization
+
Persistent Continuity
```

原则：

> **Model authors candidates; Program owns reality。**

## 5. G9-02｜Runtime Asset Binding + Context Orchestration + World Materialization Foundation

**必须位于 asset-spec vNext Schema Freeze 之前。**

### 5.1 Context Orchestration

继续证明第 15 号裁定：

```text
Player Input
+ pruned Enabled Feature/Module Directory
+ minimal scene
→ Router
→ immediate candidates
→ Program structural validation
→ state-mandatory augmentation
→ Current Relevant Set
→ bounded JIT Runtime Projection
```

### 5.2 Runtime World Materialization

新增必须证明：

```text
Player / Story need for plausible new local entity
↓
Model bounded typed proposal
↓
Program validation against canonical world constraints
↓
Program assigns/validates stable refs
↓
Atomic Materialization Plan
↓
Authoritative Runtime commit
↓
PlayerSession projection
↓
Narrative may reference / interact
↓
Save / Restore / Recovery preserve identity
```

至少覆盖：

- Dynamic Character Materialization；
- Dynamic Place / Scene / Connection Materialization。

可选随后覆盖 Item。

### 5.3 World Growth != Prompt Growth

Materialized entities 可以长期增长，但不得自动进入每回合 Context。

```text
Authoritative World Entities ↑↑↑
ordinary Turn Context ≈ bounded
```

由第 15 号 Context Orchestration 决定 current relevant projection。

## 6. G9-03｜asset-spec vNext Machine Contract

只有 G9-02 vertical proof 后才冻结。

除既有 identity / dependency / host / routing / context contract 外，未来 asset-spec 应能够表达已经被 Runtime 验证的：

- canonical anchors；
- immutable / hard constraints；
- important named entities；
- materialization eligibility / boundary；
- allowed entity kinds；
- identity / provenance / ownership；
- visibility / information boundary；
- bounded generation-relevant context；
- optional materialization policy。

不得要求资产作者预写未来每一个普通 NPC / 酒馆 / 小巷。

原则：

> **Runtime World Materializer Before Asset Materialization Schema。**
