## 3. WEB-08 最小范围

目标不是让模型做任意计划，而是让 Core 对常见的少量顺序动作有正式语义，例如：

```text
“回到酒馆，然后睡到第二天。”
```

最低要求：

1. 一个 Player Input 可以产生 bounded ordered action sequence candidate；
2. sequence 长度有明确小上限；
3. 每个子动作仍使用现有 Capability / Authorization / Resolution authority；
4. Program 确定执行顺序；
5. 所有子动作在一个 Formal Turn transaction 内提交；
6. no partial commit；
7. 任一必需子动作失败 → 整个 sequence 不产生部分世界状态；
8. worldTime 由 Program 根据成功序列统一推进；
9. Narrative 读取最终正式 sequence outcome，不重新决定结果；
10. 不建设 workflow DSL、长期 Planner、Agent loop、后台任务编排器。

详细实现边界由正式 WEB-08 task 在当前 Runtime 事实上冻结。
