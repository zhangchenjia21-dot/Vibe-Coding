## 3. Exit Gate 原则

Exit Gate 只做阶段验证，不预设一轮大规模开发。

如果发现：

- P0：authority / data / safety / atomicity / critical path broken；
- P1：当前阶段目标关键路径不可用；

则开集中修复任务。

如果发现：

- P2：重要但不阻塞 G9；
- P3：polish / copy / visual / deep accessibility；

则登记 backlog，不阻塞 G8 CLOSED。

## 4. Exit Gate 检查面

### Automated / Engineering

- current main / no unreviewed critical divergence；
- Creation → Session；
- Host production vertical；
- multi-action positive / negative / recovery；
- no-key / configured-key；
- G5 / G6 / G7 regression；
- product E2E；
- full tests；
- typecheck / lint / product build；
- launcher smoke；
- disclosure；
- desktop / narrow / keyboard / focus critical-path sanity。

### Project Owner UAT

项目所有者只验证产品体验，不承担内部竞态或数据库调试。

最低 UAT：

1. 正式 Launcher 进入 Main Menu；
2. 创建一局游戏并进入 Session；
3. 提交一个普通单动作；
4. 提交一个自然语言两步动作，例如“回到酒馆，然后等到第二天早晨”；
5. 确认 UI 仍像一次玩家输入 / 一个正式回合，而不是 Planner 或双提交；
6. 基础 Host Surface / 动态贡献未出现明显产品 blocker。

WEB-06/07 不要求在本次 UAT 中补做。
