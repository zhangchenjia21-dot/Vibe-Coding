## 3. WEB-08 的阶段定位

WEB-08 不是完整自然语言 Planner，也不是玩家产品 polish。

它只冻结会影响未来 Expansion Action Intent / Resolution Contract 的最小 Core semantics：

- 一个 Player Input 可表达少量、顺序明确的多个动作；
- 一个 Player Input 最多形成一个 Formal Turn；
- Program 拥有顺序、权限、时间推进、Resolution 与最终提交；
- 整个 multi-action 必须 atomic；
- 必要子动作失败时不能 partial commit；
- 模型只能提出受控 sequence candidate，不拥有 world commit；
- 不建设任意 workflow DSL / long-horizon planner / agent loop。

WEB-08 完成后直接进入 G8 Exit Gate，不再新增惯性功能任务。
