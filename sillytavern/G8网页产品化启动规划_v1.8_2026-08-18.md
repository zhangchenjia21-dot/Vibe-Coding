项目所有者真实 Creation → Session 测试证明：

### P1｜Semantic Placeholder World

当前 configured AI-created game 仍可能把复杂 Creation fields 压成：

- `附近的人`
- `附近区域`
- `随身物品`

数量上有 Entity，但语义错误。

### P1｜Opening Cast Cardinality

多类 opening roles 不能合并成一个 NPC。

### P1｜Living World

首次 Session 需要具体 opening cast / place / hook；合理未知地点 / NPC 需要 bounded Runtime materialization，不能让世界永久停留在静态 seed。

### P1｜Inventory Fidelity

多个随身资源必须正确成为多个 concrete Item / Resource record；Narrative inventory 与 Product Items 必须一致。

### P1｜Information IA

Information Surface 不得显示 generic `行动已完成 / 你前往XX` bookkeeping。

### P1｜Player Profile

Player Detail 必须完整消费 identity / background / goals / past / personality / language style。
