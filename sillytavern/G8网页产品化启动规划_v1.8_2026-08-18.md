## 2. Stage UAT 当前 blocker cluster

真实 UAT 证明当前仍不满足 G8 Exit：

### P0｜Narrative Authority

Narrative 不得宣称 Program Final Outcome 未提交的 Location / Entity / Item / Time / Relationship / Knowledge / Commitment / Formal Event 变化。

### P1｜Minimum Playable Runtime T0

AI-created game 的第一次正式 Session 至少需要：

```text
current Scene
+ visible authoritative non-player Character
+ public reachable destination / Connection
+ optional Item when Creation provides item/resource semantics
```

### P1｜No Phantom Interactable

具体可交互 NPC / Item / Place 必须有 authoritative referent；ambient background 可以存在，但不能在下一轮突然成为无 identity 的交互目标。

### P1｜Bounded Rich Context

`Bounded != Starved`。Narrative / recommendation 的 player-safe working set 必须保留当前职责所需的玩家身份、背景、目标、经历、语言风格、NPC public profile、真实可达地点等。

### P1｜Dynamic Five Suggested Inputs

输入框上方固定提供 exactly 5 个**当前回合、player-safe、context-sensitive** 的建议输入：

- recommendation 不拥有世界事实；
- 点击只 prefill，不自动提交；
- 只有正式提交才成为 player-input evidence；
- 不能引用不存在或隐藏的 NPC / Item / Place；
- authoritative Session state 变化后重新计算；
- provider failure 不阻塞自由输入与 Formal Turn；
- configured-key 路径需通过真实 DeepSeek Gate。
