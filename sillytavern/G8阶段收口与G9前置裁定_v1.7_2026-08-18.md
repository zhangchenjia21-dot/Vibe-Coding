## 4. 第 16 号核心裁定｜开放世界不是静态预枚举世界

新增正式上游：

`16_酒馆游戏_RuntimeWorldMaterialization与开放世界增长裁定_v1.0_2026-08-18.md`

冻结：

> **Model authors candidates; Program owns reality。**

含义：

- 模型未来可以提出新的 Character / Place / Scene / Item / Connection / bounded private seed；
- Program / Runtime 负责 validation、stable identity、ownership、atomic commit、persistence / recovery；
- Narrative 不得先创造 concrete interactable 再事后补 Runtime；
- 世界可以持续增长，但增长后的实体仍只在 current relevant 时进入模型 Context。

因此：

```text
World Growth
!= Prompt Growth
```
