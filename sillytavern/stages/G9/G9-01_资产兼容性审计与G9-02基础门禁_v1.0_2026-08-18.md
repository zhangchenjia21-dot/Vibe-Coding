## 4. G9-02 前必须补齐的 Runtime Foundation Gap

以下不是资产重写任务，而是 G9-02 的 mandatory runtime foundation。

### GAP-01｜Source Asset Lineage / Binding 缺失｜P1 G9 foundation

当前 `game_local_asset` 只记录：

```text
semantic_ref
asset_kind
coarse provenance
created_turn
```

不足以表达：
- source asset stable identity；
- source version；
- source content hash / snapshot identity；
- source → local binding ancestry；
- same source bound into multiple games；
- source update does not mutate existing game。

G9-02 必须建立正式语义：

```text
Source Asset Descriptor / Snapshot Identity
↓ bind
Game-local Asset Identity
```

精确 machine field 留给 G9-03。

### GAP-02｜Game-local Definition Revision / Typed Mutation 缺失｜P1

当前 Runtime 可以：
- 创建动态 NPC / Place；
- 改 Runtime position / holder / state；

但没有通用 typed path 修改已有 Game-local definition fields，例如：
- Character public description / current role / aliases；
- Item known/public description；
- Place / Scene public description；
- future definition-like relationship / objective fields。

必须新增：

```text
Model typed local-asset patch proposal
↓
Program owner/schema/visibility/ref validation
↓
Game-local definition revision
↓
atomic commit
↓
Projection reconcile
```

Owner UAT 的“检查信件后资料成长”作为 mandatory reference case：

```text
inspect existing Item
→ discover durable public detail
→ typed Item description patch
→ Product refresh
→ Save / Restore preserves patch
→ Source Asset unchanged
```

### GAP-03｜Full Game-local Canonical Asset Layer 仍不完整｜P1

当前 provenance ledger 只支持：

```text
region / place / scene / character / item
```

但 #16 和资产生态还需要长期 definition-like records：
- Relationship；
- Knowledge definition；
- Objective / Task；
- Expansion binding/config；
- Organization / Membership；
- Politics / Economy / War / Magic 等 Domain-owned records。

不能让 Runtime Core 为每个未来 Expansion 新增一个硬编码 owner kind。

G9-02 必须证明一个：

> **common Game-local canonical envelope + owner-typed validated payload/projection**

或等价架构。

要求：
- common identity / lineage / revision / visibility / provenance；
- payload 仍由正式 Domain Owner 的 typed validator/codec 管理；
- 禁止 arbitrary JSON / arbitrary model DB write；
- Core 不通过 display label 猜 Owner。

### GAP-04｜Runtime State Owner 可扩展性不足｜P1

当前 Runtime State owner 基本硬编码：

```text
character | item | relationship
```

不足以自然承接：
- Organization state；
- Political faction / office state；
- Treasury / population / bulk resource；
- Formation / campaign；
- Covenant / system module state；
- future domain records。

G9-02 必须建立受控 namespaced Domain State ownership seam，或等价 owner registration；不能为每个 Expansion 修改 Core enum。

### GAP-05｜Expansion Package / Feature / Module Binding Host 缺失｜P1

资产侧已有成熟：
- Package identity；
- Domain owner；
- dependencies；
- Features / Modules；
- routing profiles；
- definition registries；
- UI ownership/contribution。

当前 Runtime 没有一个正式 internal binding host 保存：

```text
Package Included
Feature Enabled
Module Enabled
Dependency availability
Routing Profile registry
Definition Registry binding
UI definition binding
```

G9-02 必须先用 handwritten normalized definitions 建立 internal production vertical；不得等待 external Markdown parser。

### GAP-06｜通用 Runtime Domain Extension Seam 缺失｜P1

当前 action candidate / event / state / consequence 很多仍是 G2–G8 固定 union / fixed type。

真实 Expansion 需要可注册但 fail-closed 的：
- Domain candidate / intent codec；
- Program handler / resolver owner；
- Formal Event / Handoff envelope；
- Domain projection provider；
- state-mandatory activation；
- optional UI definitions。

资产不能上传 JS / callback / arbitrary script。

正确边界：

```text
Asset selects / configures allowed declarative definitions
+
Built-in Runtime Domain Module owns code and validation
```

### GAP-07｜Generic Context Orchestrator 尚未实现｜P1

G8 已证明 bounded scene context 与 Materialization Need，但尚没有真正的 multi-Expansion router / JIT projection host。

G9-02 必须建立：

```text
Player Input
+ enabled/pruned Routing Directory
+ minimal current context
↓
Model-first routing / semantic decision
↓
Program validates IDs + state-mandatory augmentation
↓
JIT owner projections
↓
optional bounded cross-owner join
↓
Domain handling / Formal Outcome
↓
outcome-gated downstream continuation
```

要求继续保持：
- Program 不重复 NLP；
- Open Attempt；
- Materialization Need 继续由 AI Semantic 判断；
- World Materializer 不成为所有 Turn 固定调用；
- no full asset / full registry prompt；
- no recursive transitive dependency expansion。

### GAP-08｜Save / Restore 尚未覆盖未来 Extension records / binding revision｜P1

G8 Save 已覆盖动态 Character/Place/Scene/Item topology。

G9-02 后新增的：
- source bindings；
- Game-local definition revisions；
- Domain records；
- Domain state；
- package/feature/module activation（若可变）；

必须进入 canonical Save / Restore / Branch semantics。

不能出现：

```text
restore old save
→ future asset patch / domain record remains
```

### GAP-09｜Objective extensibility seam｜P2 / G9 architecture guard

完整 Objective Engine 不属于 G9-02 mandatory gameplay scope。

但 G9-01 必须防止 schema / Game-local layer 把 Objective 永久排除。

G9-02 至少证明：

```text
future Objective / Task
can be represented as owner-typed long-lived Game-local record
```

无需现在实现完整 objective creation/progression UI logic。
