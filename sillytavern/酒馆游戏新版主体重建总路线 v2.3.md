## 6. G9-04｜Adapter / Compiler / Binding｜AUTHORIZED / NEXT

G9-04 的唯一关键路径：

```text
current canonical Markdown Source
↓ AI-independent adapter / parser
TavernAssetV1
↓ deterministic validate / canonicalize / SHA-256
TavernGameAssetManifestV1
↓ compiler / binding
existing G9-02 SourceAssetDescriptor
↓
Game-local Binding / lineage / revision
```

### 三类主资产

必须至少使用当前 canonical real samples 证明：

- World Pack → `TavernAssetV1(world)`；
- Character Card → `TavernAssetV1(character)`；
- Expansion Pack → `TavernAssetV1(expansion)`；
- identity / version / owner / typed dependency / feature/module declarations 无损；
- Expansion Source module → `runtimeModuleRef` mapping 遵守 G9-03A；
- Game Asset Manifest exact snapshot 可进入既有 Source Binding rails；
- Source update 不静默改变 Existing Game；
- parser / compiler 不调用模型，Manual / future AI-assisted authoring 最终使用同一合法 Source contract。

### 资料库

G9-04 只允许最小协议 proof：

```text
Library sample
→ parse
→ validate
→ canonical serialize / round-trip
→ cross-reference validation
```

明确不允许提前实现：

- Library “我的资产库”产品页面；
- 创建游戏中的真实 Library binding UX；
- Runtime indexing / retrieval；
- Model Reference Provider；
- Creator Library editor。

### G9-04 Architecture Stop Rule

若真实 canonical Markdown 资产暴露 `tavern.asset.v1` 无法表达的 P0/P1 protocol blocker：

```text
STOP
→ GPT architecture review
```

禁止 adapter 私自加第二 wire / hidden sidecar schema / arbitrary fallback JSON 来绕过 frozen protocol。
