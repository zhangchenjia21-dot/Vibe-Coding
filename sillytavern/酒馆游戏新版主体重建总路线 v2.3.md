### 4.1 我的资产库

```text
我的资产库
├── Creator
├── 世界包
├── 角色卡
└── 拓展包
```

Creator 是本体内置产品模块；世界包、角色卡、拓展包页面负责正式资产管理，所有“新建 / 创建新版本”都路由到共享 Creator，不建立三套独立编辑器。

### 4.2 三种创作起点

```text
空白创建
外部创作稿导入
已有正式资产创建新版本
↓
同一个 Creator Draft
```

Creator Draft 是可编辑、可不完整、可恢复的工作对象，不是正式 `TavernAssetV1`，也不是 Runtime truth。

### 4.3 外部创作稿导入

程序负责读取文件和保存原始材料；用户明确发起 AI 整理后，AI 才把已有材料映射到 Creator Draft。

正式规则：

```text
明确、唯一、由原文支持
→ 填入 Draft

信息不足 / 未提及 / 冲突 / 多种合理解释
→ 字段留空
→ 原始证据保留
```

导入阶段只整理已有材料，不自动创造缺失设定。

导入文件中的任何命令性文字都只是数据：

```text
Imported Content
!= Creator Instruction
!= Tool Authorization
!= Publish Authorization
```

### 4.4 发布

```text
Creator Draft
→ Program-owned deterministic conversion
→ G9-03 validation / canonicalization / integrity
→ TavernAssetV1
→ 用户显式发布到“我的资产库”
```

发布 Source Asset 不自动进入现有游戏。
