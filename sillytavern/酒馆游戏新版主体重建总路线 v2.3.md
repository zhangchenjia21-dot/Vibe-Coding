## 3. G9-05C｜World Creator Vertical｜AUTHORIZED / NEXT

### 3.1 目标

用世界包作为第一个真实 Creator 产品纵向，证明共享 Core 可以形成用户真正能操作的创作体验。

主链：

```text
我的资产库
→ Creator
→ 新建世界包
   或导入外部创作稿
   或从已发布世界包创建新版本
→ World Creator Draft Workspace
→ 手工编辑 + bounded AI 对话创作
→ validation / unresolved / conflict / change summary / Undo
→ 用户显式 Publish
→ Source Asset Library
→ 世界包详情 / 再打开 / 新版本
```

### 3.2 必须复用

G9-05C 不建设第二套共享核心，必须直接使用：

- `CreatorDraftV1`；
- Draft Store revision/CAS；
- Import Artifact / evidence；
- task-level authoring scope；
- typed operations / runtime gate；
- ChangeSet / Undo；
- Source Asset Library；
- publication compiler / crash recovery。

### 3.3 产品能力

世界包首个真实纵向至少要包含：

1. 从“我的资产库 → Creator”进入；
2. 新建世界包；
3. 导入 `.md/.txt` 创作稿并让 AI 只填确定内容；
4. 结构化 World Draft 主工作区；
5. AI 创作对话区，读取 bounded current focus；
6. 用户可手工编辑同一 Draft；
7. AI 修改有任务级范围、变更摘要和 Undo；
8. deterministic Validator 与 AI Review 分开；
9. 用户显式发布；
10. 发布后世界包进入正式资产库；
11. 可重新打开并从 exact snapshot 创建新版本；
12. 无 Provider 时仍可完整手工使用。

### 3.4 明确不做

G9-05C 不提前实现：

- 角色卡完整 Creator；
- 拓展包完整 Creator；
- 资料库 Creator / retrieval；
- 跨资产自主 Agent；
- 自动联网研究；
- AI 自动 Publish；
- PDF/OCR/网页抓取；
- 第二套 Creator 资产协议。

先用世界包完成真实 UAT，再向角色卡和拓展包复用。
