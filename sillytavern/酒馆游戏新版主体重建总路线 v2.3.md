### 5.1 Semantic Freeze｜PASS

v1 正式冻结：

```text

= one Source Envelope
+ world | character | expansion | library typed payload
```

```text

+ assetType
+ version
+ sha256 content hash
```

该 identity 必须直接映射既有 G9-02 `SourceAssetDescriptor`，不得另造 Runtime source identity。

同时冻结：

- Hard / Optional / Feature-conditional / Reference dependencies；
- World default / recommended / optional composition；
- Expansion Package / Feature / Module hierarchy；
- Program-registered `runtimeModuleRef` / config schema / projection seam；
- minimal Model-first routing profile；
- G8 Host-safe UI declaration seam；
- Library stable entry / provenance / 4-audience eligibility；
- no arbitrary retrieval DSL / embedding / vector contract；
- `TavernBundleManifestV1` transport；
- `TavernGameAssetManifestV1` exact resolved source snapshot binding；
- deterministic canonical serialization + SHA-256；
- compatibility / explicit rebind / migration seam；
- fail-closed validator error classes。
