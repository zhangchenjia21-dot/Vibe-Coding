## 9. G9-03｜统一资产 / 资料资源协议冻结

只有 02C breadth 与 G9-02 Integrated Closure 全部 PASS 后才能冻结 external asset/resource contract。

### 三类主资产

必须覆盖：

- 身份 / 版本 / 完整性；
- source → local binding；
- immutable / evolvable / private policy；
- Owner / namespace；
- dependency / conditional / handoff / contribution；
- package / feature / module activation；
- routing / context contract；
- UI declaration；
- materialization / mutation eligibility；
- runtime binding metadata；
- compatibility / migration；
- Manifest / Bundle relationship。

### 资料库

同批冻结 #18 / #18A 所需：

- stable library identity / version / integrity；
- stable entry identity / provenance；
- 主资产对资料库的引用；
- 世界包绑定 `0..N` 资料库；
- default / recommended / optional；
- visibility / audience / disclosure 扩展挂点；
- Reference Projection 与 Game-local / Runtime Truth 边界；
- Bundle / Manifest / import / export；
- compatibility / migration；
- 有界检索所需最小声明能力。

### Creator #19 对 G9-03 的约束

G9-03 必须让 Source Asset contract 具有稳定、可寻址、可验证的 field / ref / identity 语义，使 Creator Tool 能可靠编辑。

但必须保持：

```text
Asset Contract
!= Creator Tool Contract
!= Conversation Protocol
```

不得把以下 Creator 实现细节写入资产协议：

- chat history；
- prompt；
- model provider；
- AI action history；
- Creator tool transport。

## 11. G9-05｜Conversational Authoring Creator 基础闭环

正式 Authority：`19_酒馆游戏_CreatorConversationalAuthoring与AI协作式结构化创作裁定_v1.0_2026-08-19.md`。

G9-05 首版产品定义：

```text
Structured Creator Workspace
+
Conversational AI Authoring
```

### 必须存在

1. 世界包 / 角色卡 / 拓展包结构化主工作区；
2. 持续 AI 创作对话区；
3. AI 能读取 bounded current asset / section / focus context；
4. 用户可以用自然语言描述创作需求；
5. AI 只做最少必要追问；
6. AI 通过 Program-owned Typed Creator Tools 修改 Draft；
7. AI 不直接操作 DOM；
8. 修改即时反映到结构化主工作区；
9. 任务级变更摘要 / Undo；
10. deterministic Validator；
11. AI Review / Validator explanation；
12. 用户显式 Save / Publish；
13. 无 API / Provider unavailable 时完整手工 Creator 仍可用；
14. 导入 / 导出并回到“我的资产库”继续编辑。

### Authority

```text
AI Chat
!= Creator Draft

Creator Draft
!= Saved Source Asset

AI can edit Draft
!= AI can publish asset
```

### 首个真实纵向

优先世界包：

```text
自然语言世界创意
→ 少量关键追问
→ AI 填充结构化 Draft
→ 主工作区可见
→ 手工 / 对话继续迭代
→ Validator
→ Undo
→ 用户保存
→ 导入 / 导出 / 再打开
```

角色卡与拓展包随后复用同一 Creator rails；G9-05 关闭前，三类主资产都必须完成基础创作链。

### 明确不做

- 资料库真实检索增强；
- 跨多个资产的大规模自主操作；
- 长时间自主 Agent；
- 自动联网研究；
- 通用 autonomous-agent runtime；
- 自动 Save / Publish。

前三项只记录在 `Creator_AI后续可选增量备忘录_v1.0_2026-08-19.md`，属于 `DEFERRED OPTIONAL / NOT ROADMAP COMMITMENT`。
