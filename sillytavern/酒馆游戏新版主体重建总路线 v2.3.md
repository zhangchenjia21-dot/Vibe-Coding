## 5. G9-05B｜Creator Core Contract｜PASS / FROZEN

正式规格：

`G9-05B_CreatorCore草稿导入发布内部合同规格_v1.0_2026-08-20.md`

### 5.1 长期 Owner

```text
Creator Draft Store
= 可编辑草稿、导入证据、变更集、撤销工作状态

Source Asset Library Store
= 已通过 G9-03 校验的正式本地 Source Asset
```

二者均不是 Runtime State；用户本地 Source Asset Library 也不等于研发仓库 `sillytavern-assets`。

### 5.2 Draft 身份

```text
CreatorDraftV1
= draftRef
+ assetType
+ Program-minted targetAssetRef
+ targetVersion?
+ origin
+ lifecycle
+ revision
+ partial formal content
+ workState
```

新资产身份不从标题、文件名、别名或 AI 输出生成。已有资产新版本精确继承基础 `assetRef`。

### 5.3 并发 / AI

所有修改 CAS 自动保存；AI 请求绑定 exact `basisRevision`，迟到结果丢弃。

导入 AI 只填空白且有原文 evidence 的确定项；不静默覆盖已有用户内容。

### 5.4 任务级撤销

每个 AI / 用户任务形成 Program-owned change set。撤销通过 inverse change 创建新 revision；目标后来已被修改则失败关闭，不抹掉新内容。

### 5.5 正式资产库

```text
assetRef + version 不存在
→ append

存在且 digest 相同
→ 幂等成功

存在但 digest 不同
→ SOURCE_ASSET_VERSION_CONFLICT
```

绝不覆盖。

### 5.6 发布与恢复

```text
editable
↓ G9-03 candidate validation
publishing
↓ append exact Source
published
```

发布崩溃后可以根据 intended snapshot 精确认领同一 Source，避免重复版本。
