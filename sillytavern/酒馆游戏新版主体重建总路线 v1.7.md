# 5. 当前工程原则

1. **Single Authority**：一个事实一个 Owner。
2. **Shared Foundation Before Consumers**：核心能力先收口，再让多个消费者接入。
3. **Host Before Protocol**：Game Host 先真实验证，再设计外部声明协议。
4. **Declarative Structure ≠ Live Data**：声明层不拥有任意 Runtime 读取权。
5. **Supersession Before Compatibility**：无真实兼容义务时，新架构完整替代旧实现就退休旧路径。
6. **Dependency Graph != Context Inclusion Graph**：模块依赖不等于模型上下文全量注入。
7. **Program Authority**：状态、权限、RNG、判定、提交、恢复由程序拥有。
8. **Model Bounded Role**：模型负责语义理解/建议/叙事，不拥有正式 world commit。
9. **Product UX 可以按阶段成熟度分级**：个人开发阶段可延后不改变下游协议的消费层 UX；进入 Alpha 前重新拉回。
10. **Push ≠ PASS**：实现者 push 后仍需 GitHub-first Independent Review。
