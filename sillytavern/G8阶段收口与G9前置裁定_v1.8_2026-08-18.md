## 3. 第 16 号核心裁定升级

第 16 号 current source 更新为：

`16_酒馆游戏_RuntimeWorldMaterialization与当局游戏资产演化裁定_v1.1_2026-08-18.md`

核心三层：

```text
Source Asset Library
↓ snapshot / bind
Game-local Canonical Assets｜当局游戏资产
↓ runtime instantiate / projection
Authoritative Runtime State
```

冻结：

- Source World Pack / Character Card / Expansion 不被运行期模型反向修改；
- 创建游戏后，本局形成独立当局游戏资产；
- 模型可以在 Program-owned typed mutation contract 内创建、补全、修改当局游戏资产真实字段；
- 新 NPC / Place / Item 一旦接受，成为本局 canonical asset，而不是 Narrative-only entity；
- Runtime State 与当局资产定义分离；
- Save / Restore 必须恢复当局资产 revision 与 Runtime State 的一致边界。

原则：

> **Source assets are templates; game-local assets are living canonical world definitions.**

> **Models may author and evolve game-local reality, but only through Program-owned typed commit boundaries.**
