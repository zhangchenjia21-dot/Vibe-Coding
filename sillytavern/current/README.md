# current｜当前项目入口

这里是 AI 恢复 SillyTavern 当前项目语义的第一站。文件名保持稳定，内容随项目演进原位更新；版本历史由 Git 保存。

## 默认读取顺序

1. `项目开发核心总纲.md` —— 项目级 current Owner。
2. `核心游玩重构_产品与架构总纲.md` —— 当前产品与架构解释层。
3. 任务涉及路线时再读 `新版主体重建总路线.md`。
4. 任务涉及旧主体继承边界时读 `第二版主体停止修补与继承策略.md`。

## 写入规则

- 本目录只保留少量 rolling canonical。
- 更新上述 Owner 时直接原位修改，不新增 `*_CURRENT.md`、`v2.5`、`最终版2` 等平行文件。
- 具体架构裁定下沉 `../architecture/`；阶段规格、Review、Correction 与 Gate 证据下沉 `../stages/`。
- 当前状态变化后，只更新确有依赖的路由与派生视图，不复制第二份 current truth。
